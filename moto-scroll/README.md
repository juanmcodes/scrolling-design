# Moto Scroll – JuanchoDev

Página con animación de moto controlada por el scroll (150 fotogramas).

## Cómo correrlo
Abre `index.html` con doble clic. No necesita instalar nada ni servidor.
(Opcional: `npx serve` dentro de esta carpeta.)

## Estructura
- `index.html` – contenido
- `styles.css` – estilos
- `frames.js` – lógica del scroll
- `images.js` – los fotogramas (en base64)
- `assets/` – logo, favicon y cuadrícula

## Créditos
Basado en el proyecto original de BeruzDev (https://github.com/BeruzDev/ichiban-scroll),
a su vez un clon de https://www.ichiban.bike/. Adaptado por JuanchoDev.
